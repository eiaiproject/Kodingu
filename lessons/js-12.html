Modern JavaScript

Types, truthiness, and equality

JavaScript 8 min 25 XP Lesson 12 of 19
Goal

Display the type of a number and compare a number with a numeric string using strict equality.

A value has a type. Strings, numbers, booleans, undefined, null, symbols, and bigints are primitives. Arrays and objects are reference values. typeof returns a short name for most of them.

js
const count = 3;
const label = '3';

document.querySelector('#type').textContent = typeof count;
document.querySelector('#value').textContent =
  count === Number(label) ? 'same number' : 'different';

The triple equals compares type and value. The double equals converts first, so 3 == "3" is true. Convert on purpose with Number() or String(), then compare the result.

Note

NaN is a number by type, and null reports as object. Use Number.isNaN() and an explicit null check instead of guessing from typeof.

Your turn

Challenge

Create count as 3 and label as "3". Show the type of count in #type, then compare count with the converted label using strict equality and show "same number" in #value.

  • Declare const count as 3.
  • Declare const label as "3".
  • Write typeof count into #type.
  • Convert label with Number().
  • Use === to compare the two numbers and write "same number" into #value.
