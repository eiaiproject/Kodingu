A page that holds together

Capstone: a field notes page

HTML 12 min 40 XP Lesson 20 of 32
Goal

Build one page with landmarks, a figure, a list, and a working jump link.

This page brings the module together. A reader should be able to find the header, jump to the notes, read an article, see a captioned figure, and reach the footer without guessing.

html
<header>
  <h1>Field notes</h1>
  <nav><a href="#notes">Notes</a></nav>
</header>
<main id="notes">
  <article>
    <h2>A page is a tree</h2>
    <p>Structure comes before style.</p>
  </article>
</main>
<footer><p>Kodingu</p></footer>

Start with the regions, then fill them. Keep one h1, put the article inside main, and give every image useful alt text. A figure is a good home for an image and its caption.

Note

The page should still make sense with the styles removed. That is the test of good structure.

Your turn

Challenge

Build the field notes page. Use a header with a nav, a main article with a figure and a list, and a footer. The nav link should jump to main.

  • Set the title to "Field notes".
  • Use one header with an h1 "Field notes" and a nav link to #notes that says "Notes".
  • Use one main with id="notes" containing one article.
  • Put an h2 "A page is a tree", a paragraph, a figure, and a ul inside the article.
  • The figure needs the seal image with alt "A vermilion square" and the caption "The Kodingu seal".
  • The list has two items: Structure and Style.
  • Use one footer with the text "Kodingu".
