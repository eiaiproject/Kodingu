Forms and tables

Row headers

HTML 8 min 25 XP Lesson 15 of 32
Goal

Use th scope="row" to name each row in a table.

A table can have column headers and row headers. A row header names the row, like a week or a name. Put a th as the first cell in the row and set scope to row.

html
<table>
  <caption>Reading log</caption>
  <thead>
    <tr><th scope="col">Week</th><th scope="col">Pages</th></tr>
  </thead>
  <tbody>
    <tr><th scope="row">One</th><td>24</td></tr>
    <tr><th scope="row">Two</th><td>31</td></tr>
  </tbody>
</table>

Header cells are not limited to the top row. A th in the first column gives each row a name that a screen reader can announce with its data.

Note

Keep numbers in td cells and names in th cells. That keeps the relationship between the header and the value clear.

Your turn

Challenge

Build a reading log table with two weeks. Each row needs a row header and a page count.

  • Use one table with the caption "Reading log".
  • Put column headers Week and Pages in thead with scope="col".
  • Put two rows in tbody.
  • Start each row with th scope="row": One and Two.
  • Put the page counts 24 and 31 in td cells.
