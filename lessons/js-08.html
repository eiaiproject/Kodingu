The page responds

Capstone: a field notes counter

JavaScript 12 min 40 XP Lesson 8 of 19
Goal

Build a counter that adds notes and resets the list.

This page combines state, events, and DOM changes. A counter tracks how many notes exist. The Add note button writes the count and appends an item. The Reset button clears both.

js
let count = 0;

addButton.addEventListener('click', () => {
  count += 1;
  const item = document.createElement('li');
  item.textContent = `Note ${count}`;
  list.append(item);
});

resetButton.addEventListener('click', () => {
  count = 0;
  list.replaceChildren();
});

Use the count to decide between note and notes. ReplaceChildren removes every child in one step, which is cleaner than removing items one at a time.

Note

Keep the state and the page in sync in the same handler. If one changes without the other, the next click will show the mismatch. The preview is a snapshot, so use Check to exercise the buttons.

Your turn

Challenge

Build the field notes counter. Add note increases the count and appends a note. Reset clears the count and the list.

  • Start with count at 0 and show "0 notes".
  • On Add note, increase count and show "1 note" or "2 notes".
  • Append an li that says "Note 1", "Note 2", and so on.
  • On Reset, show "0 notes" and remove every list item.
  • Use one click listener for each button.
