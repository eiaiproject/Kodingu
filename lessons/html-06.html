Images need alt text

HTML 7 min 25 XP Lesson 6 of 32
Goal

Add an image with a src and a useful alt description.

The img element puts an image on the page. It is a void element, so it has no closing tag. Two attributes do most of the work: src points to the image, and alt describes it.

html
<img src="seal.svg" alt="A vermilion square">

Alt text is what a screen reader announces when the image cannot be seen. Describe the image in the context of the page. If the image is purely decorative, use an empty alt attribute so the screen reader can skip it.

Note

Do not start alt text with "Image of". A screen reader already says that it is an image.

Your turn

Challenge
