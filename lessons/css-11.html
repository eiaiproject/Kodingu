Layout

A page that bends

CSS 10 min 25 XP Lesson 11 of 19
Goal

Start with one column and add a second column at a wider screen.

A responsive page starts with the small screen. Write the one-column layout first, then add a media query for wider screens. This keeps the phone layout simple instead of overriding a desktop layout.

css
.layout {
  display: grid;
  grid-template-columns: 1fr;
  gap: 1.5rem;
}

@media (min-width: 640px) {
  .layout {
    grid-template-columns: 2fr 1fr;
  }
}

A media query applies its rules only when the condition is true. Min-width: 640px means 640 pixels and wider. Below that, the single column stays in place.

Note

Use em or rem in breakpoints when you can. They follow the reader font size, while pixels stay fixed.

Your turn

Challenge

Start the layout as one column with a 1.5rem gap. At 640px and wider, change it to a 2fr and 1fr grid.

  • Set .layout display to grid.
  • Set the base grid-template-columns to 1fr.
  • Set the gap to 1.5rem.
  • Add a media query for min-width: 640px.
  • Inside the media query, set .layout grid-template-columns to 2fr 1fr.
