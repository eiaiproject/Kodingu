Layout

Place items on the grid

CSS 9 min 25 XP Lesson 10 of 19
Goal

Span one item across every column of a two-column grid.

Grid items land in the next open cell, row by row. You can place one item by hand. Grid-column: 1 / -1 starts at the first column line and ends at the last one, so the item spans the full row.

css
.grid {
  display: grid;
  grid-template-columns: 1fr 2fr;
  gap: 1rem;
}

.wide {
  grid-column: 1 / -1;
}

The first column takes one share and the second takes two. The header spans both, then the side and main sections fill the next row in that order.

Note

Line numbers start at 1. The last line is -1. Spanning 1 / -1 works even when the number of columns changes later.

Your turn

Challenge

Build a two-column grid where the first column takes one share and the second takes two. Make the header span the full row.

  • Target the .grid container.
  • Set display to grid.
  • Set grid-template-columns to 1fr 2fr.
  • Set gap to 1rem.
  • Make .wide span from the first line to the last line.
