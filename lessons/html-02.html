The shape of a page

Headings carry rank

HTML 7 min 25 XP Lesson 2 of 32
Goal

Use one h1 and two h2 elements to give a page a clear outline.

Headings are labels for the content below them. HTML gives you six ranks, from h1 to h6. The rank is about importance, not font size.

html
<h1>Kodingu field notes</h1>
<h2>HTML</h2>
<p>Structure comes first.</p>
<h2>CSS</h2>
<p>Style comes next.</p>

A page usually has one h1. It names the page. Sections inside the page use h2, and subsections use h3. Skipping a rank to make a heading look smaller makes the outline harder to follow.

Note

A heading is a label for the content below it. Use CSS when you want to change how it looks.

Your turn

Challenge

Build a page with one h1 that says "Kodingu field notes" and two h2 sections: "HTML" and "CSS".

  • Use exactly one h1.
  • Use exactly two h2 elements.
  • The h1 text is "Kodingu field notes".
  • The h2 texts are "HTML" and "CSS", in that order.
