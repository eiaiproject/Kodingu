Forms and tables

Tables hold data

HTML 9 min 25 XP Lesson 14 of 32
Goal

Build a table with a caption, column headers, and one data row.

A table is for data that belongs in rows and columns. It is not a layout tool. The caption names the table. The thead holds the header row, and the tbody holds the data rows.

html
<table>
  <caption>Lesson plan</caption>
  <thead>
    <tr><th scope="col">Day</th><th scope="col">Topic</th></tr>
  </thead>
  <tbody>
    <tr><td>Monday</td><td>HTML</td></tr>
  </tbody>
</table>

Use th for header cells and td for data cells. The scope attribute tells a screen reader whether a header belongs to a column or a row.

Note

The caption is part of the table. Do not replace it with a heading above the table.

Your turn

Challenge

Build a table titled "Lesson plan" with two column headers, Day and Topic, and one data row for Monday and HTML.

  • Use one table with the caption "Lesson plan".
  • Put one header row in thead with th scope="col" cells Day and Topic.
  • Put one data row in tbody with the cells Monday and HTML.
  • Use td for the data cells.
