JSON and async

JavaScript 9 min 25 XP Lesson 15 of 19
Goal

Parse a JSON payload inside an async function and display its title and count.

JSON is a text format for data. JSON.parse turns text into a JavaScript value. JSON.stringify goes the other way. A network request returns a promise, a value that will arrive later.

js
const payload = '{"title":"Field notes","count":3}';

async function show() {
  const data = await Promise.resolve(JSON.parse(payload));
  document.querySelector('#title').textContent = data.title;
  document.querySelector('#summary').textContent = `${data.count} notes`;
}

show();

An async function always returns a promise. Await pauses that function until the promise settles, without blocking the rest of the page. The code after await runs when the value is ready.

Note

JSON keys and string values use double quotes. JSON.parse throws on invalid text, so a real request belongs in a try and catch block.
