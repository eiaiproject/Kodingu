The page responds

Find and change the page

JavaScript 9 min 25 XP Lesson 6 of 19
Goal

Select one element and a group of elements, then change both.

Document.querySelector returns the first element that matches a CSS selector. Document.querySelectorAll returns every match as a NodeList. A NodeList has forEach, so you can work on each element in turn.

js
document.querySelector('#page-title').textContent = 'Field notes';

document.querySelectorAll('.note').forEach((note, index) => {
  note.textContent = `Note ${index + 1}`;
  note.classList.add('is-set');
});

ClassList.add puts a class on an element without replacing the classes it already has. The index in forEach starts at 0, so index + 1 gives the visible note number.

Note

The selector syntax is the same one CSS uses. A hash finds an id, a dot finds a class, and a bare word finds an element.

Your turn

Challenge

Change the page title to "Field notes". Number the two notes "Note 1" and "Note 2", and give each one the class is-set.

  • Set #page-title to "Field notes".
  • Select every .note with querySelectorAll.
  • Set the notes to "Note 1" and "Note 2".
  • Add the class is-set to both notes.
