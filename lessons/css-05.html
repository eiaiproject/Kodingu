Type and spacing

CSS 8 min 25 XP Lesson 5 of 19
Goal

Set a type stack, a readable line height, and simple spacing.

Font-family takes a list. The browser uses the first font it can find, so end the list with a generic family like serif or sans-serif. Font-size sets the scale. Line-height sets the space between lines.

css
body {
  font-family: Georgia, serif;
  font-size: 1rem;
  line-height: 1.6;
}

h1 {
  font-size: 2rem;
  margin-bottom: 0.5rem;
}

p {
  margin-bottom: 1rem;
}

A unitless line-height is a multiplier of the font size, so it scales when the text grows. A pixel line-height stays fixed and can crowd larger text.

Note

Use a small type scale. Two or three sizes are usually enough for a lesson page.
