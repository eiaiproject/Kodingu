Surfaces and states

States and generated content

CSS 9 min 25 XP Lesson 17 of 19
Goal

Give a link a hover color, a visible focus ring, and a generated New label.

A pseudo-class selects an element in a state. :hover applies while the pointer is over it. :focus-visible applies when keyboard focus should be visible. These states tell the reader that the page heard them.

css
.link:hover {
  color: #b23a2f;
}

.link:focus-visible {
  outline: 2px solid #b23a2f;
  outline-offset: 2px;
}

.note::before {
  content: "New";
  color: #b23a2f;
  margin-right: 0.5rem;
}

A pseudo-element creates a part that is not in the HTML. ::before inserts content at the start of the element. It needs the content property, even when the value is an empty string.

Note

Do not remove a focus outline without replacing it. The focus ring is how a keyboard user knows which control will respond.

Your turn

Challenge

Make .link turn #b23a2f on hover. Give .link:focus-visible a 2px solid #b23a2f outline with a 2px offset. Add the generated text "New" before .note.

  • Set .link:hover color to #b23a2f.
  • Set .link:focus-visible outline to 2px solid #b23a2f.
  • Set .link:focus-visible outline-offset to 2px.
  • Add content: "New" to .note::before.
