Color and contrast

CSS 9 min 25 XP Lesson 4 of 19
Goal

Set readable text and background colors with enough contrast.

Color sets the text. Background-color sets the surface behind it. The two need enough contrast to read. WCAG AA asks for at least 4.5:1 for normal body text and 3:1 for large text.

css
body {
  color: #1f1d1a;
  background-color: #f3efe6;
}

a {
  color: #b23a2f;
}

Contrast is a ratio, not a feeling. Dark ink on warm paper is easy to read. A pale gray on white may look calm and still fail.

Note

Do not use color alone to carry meaning. Add a label, a line, or another cue.

Your turn

Challenge

Set the page text to #1f1d1a on #f3efe6, and make links #b23a2f. Both pairs should pass 4.5:1.

  • Set body color to #1f1d1a.
  • Set body background-color to #f3efe6.
  • Set a color to #b23a2f.
  • Both text pairs must reach 4.5:1 contrast.
