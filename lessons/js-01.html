Values and the page

Values and variables

JavaScript 8 min 25 XP Lesson 1 of 19
Goal

Store text and a number in variables, then write them into the page.

JavaScript runs in the browser after the page is parsed. It can read the page, change it, and respond to a click. A variable is a name for a value you want to use more than once.

js
const topic = 'Field notes';
let count = 3;

document.querySelector('#title').textContent = topic;
document.querySelector('#summary').textContent = `${count} notes`;

Use const for a value that will not be reassigned, and let for one that will change. The textContent property replaces the text inside an element. A template literal uses backticks and inserts a value with ${}.

Note

JavaScript is case-sensitive. topic and Topic are two different names.

Your turn

Challenge

Create a const named topic with the value "Field notes" and a let named count with the value 3. Write them into the page.

  • Declare const topic as "Field notes".
  • Declare let count as 3.
  • Set #title to "Field notes".
  • Set #summary to "3 notes".
