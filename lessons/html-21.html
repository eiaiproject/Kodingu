Metadata and sharing

Metadata search engines read

HTML 9 min 25 XP Lesson 21 of 32
Goal

Give a page a language, a title, a description, a canonical address, and a robots rule.

The head of a document describes the page to machines. Search engines read the title, the description, the canonical address, and the robots rule before they read a single paragraph.

html
<html lang="en">
  <head>
    <title>Kodingu field notes</title>
    <meta name="description" content="Short notes about the web.">
    <link rel="canonical" href="https://example.com/notes">
    <meta name="robots" content="index, follow">
  </head>
</html>

The lang attribute names the language of the text. The title is the label in a search result and in a browser tab. The description is the sentence under that label.

Note

A canonical link tells a search engine which address is the real one when the same page is reachable at more than one URL. It prevents duplicate pages from competing with each other.

The robots rule says whether a page may be indexed. "index, follow" is the default for a public page. "noindex" keeps a page out of search results and belongs on private or duplicate pages.

Your turn

Challenge

Complete the document. Give the html element the language "en", set the title to "Kodingu field notes", add the description "Short notes about the web.", point the canonical link at https://example.com/notes, and allow indexing.

  • Set the title to "Kodingu field notes".
  • Add a description meta tag with the text "Short notes about the web.".
