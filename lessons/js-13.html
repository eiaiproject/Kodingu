Modern JavaScript

Closures keep state

JavaScript 9 min 25 XP Lesson 13 of 19
Goal

Create a makeCounter factory that returns an arrow function and remembers its count.

Scope decides where a name can be read. A let or const declared inside a block exists only in that block. A function can keep a reference to a variable from the scope where it was created. That is a closure.

js
function makeCounter() {
  let count = 0;
  return () => {
    count += 1;
    return count;
  };
}

const next = makeCounter();

Each call to makeCounter creates a new count. The returned arrow function closes over that variable, so it can change it after makeCounter has returned. No global variable is needed.

Note

Arrow functions do not have their own this. That is useful in callbacks, but use a regular function when you need this from the object that called it.
