Semantic sections

HTML 9 min 25 XP Lesson 10 of 32
Goal

Describe a page with header, main, article, and footer.

HTML has elements that describe the role of a block. Header introduces a page or a section. Nav holds major navigation. Main holds the main content. Footer closes a page or a section. Article is a self-contained piece. Section is a thematic group with a heading.

html
<header><h1>Field notes</h1></header>
<main>
  <article>
    <h2>A page is a tree</h2>
    <p>Structure comes first.</p>
  </article>
</main>
<footer><p>Kodingu</p></footer>

A page has one main element. Header and footer can wrap the whole page or one article. An article can stand on its own; a section usually needs a heading and belongs to a larger piece.

Note

Use a div only when no semantic element fits. A page full of divs is harder to navigate with a screen reader.

Your turn

Challenge

Build a page with a header containing an h1 "Field notes", a main containing an article with an h2 "A page is a tree" and a paragraph, and a footer containing "Kodingu".

  • Use one header with an h1.
  • Use one main with one article inside it.
  • Put an h2 and a p inside the article.
  • Use one footer with the text "Kodingu".
