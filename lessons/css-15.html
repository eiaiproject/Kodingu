Modern CSS

Motion that respects the reader

CSS 9 min 25 XP Lesson 15 of 19
Goal

Add a short hover transition and remove it for people who ask for less motion.

A transition moves a property from one value to another over time. One hundred and fifty milliseconds is enough to feel smooth without delaying the reader.

css
.card {
  transition: transform 150ms ease;
}

.card:hover {
  transform: translateY(-2px);
}

@media (prefers-reduced-motion: reduce) {
  .card {
    transition: none;
  }
}

The hover rule only applies while the pointer is over the card. The media query applies when the operating system reports that the reader prefers less motion.

Note

Transition the property that changes, not all of them. transition: all hides which properties are animating and can surprise the reader.

Your turn

Challenge

Transition the transform of .card over 150ms, lift it 2px on hover, and remove the transition when the reader prefers reduced motion.

  • Give .card a transition on transform of 150ms.
  • Lift .card:hover with translateY(-2px).
  • Inside a prefers-reduced-motion: reduce query, set .card transition to none.
