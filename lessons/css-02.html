Selectors point at elements

CSS 8 min 25 XP Lesson 2 of 19
Goal

Target an element, a class, and an id with the right selector.

An element selector names a tag: p, h1, a. A class selector starts with a dot and matches class="note". An id selector starts with a hash and matches id="intro".

css
p {
  color: #1f1d1a;
}

.note {
  color: #b23a2f;
}

#intro {
  font-weight: 600;
}

Classes are for groups, so they are the usual choice for styling. Ids are for one element. An id is also more specific than a class, which matters when two rules set the same property.

Note

A selector only needs enough detail to find the element. Long chains of tags and classes are hard to reuse.

Your turn

Challenge

Write three rules: paragraphs in ink, notes in vermilion, and the intro in semibold.

  • Set p color to #1f1d1a.
  • Set .note color to #b23a2f.
  • Set #intro font-weight to 600.
