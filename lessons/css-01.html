A rule has two parts

CSS 7 min 25 XP Lesson 1 of 19
Goal

Write a CSS rule with a selector and a declaration.

A CSS rule points at an element and says how it should look. The selector comes first, then a block of declarations in braces. Each declaration is a property, a colon, a value, and a semicolon.

css
h1 {
  color: #b23a2f;
}

This rule selects every h1 on the page and sets its text color. The selector is h1. The declaration is color: #b23a2f. The semicolon ends the declaration.

Note

CSS comments use /* and */. They are useful for section labels, but do not leave commented-out code behind.

Your turn

Challenge

Write one rule that selects every h1 and sets its color to #b23a2f.

  • Use the h1 selector.
  • Set color to #b23a2f.
  • Put the declaration inside braces and end it with a semicolon.
