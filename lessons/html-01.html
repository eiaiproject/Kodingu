The shape of a page

A page is a tree

HTML 8 min 25 XP Lesson 1 of 32
Goal

Write a complete HTML document and put a heading in the body.

HTML gives a page its structure. The browser reads your markup and builds a tree of elements. The tree starts with the document, then the html element, then the head and body.

html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <title>My first page</title>
  </head>
  <body>
    <h1>Hello, Kodingu</h1>
  </body>
</html>

The head holds information about the page, like its title and character set. The body holds what people see.

Note

Indentation is for humans. The browser does not care about extra spaces, but a tidy tree is easier to read and fix.

Your turn

Challenge

Write a complete HTML document. Give it the title "My first page" and put an h1 in the body that says "Hello, Kodingu".

  • Start with <!DOCTYPE html>.
  • Include html, head, and body elements.
  • Set the title to "My first page".
  • Put an h1 in the body with the text "Hello, Kodingu".
