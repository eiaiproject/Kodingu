Metadata and sharing

Structured data with JSON-LD

HTML 9 min 25 XP Lesson 23 of 32
Goal

Describe a course to search engines with a JSON-LD block using schema.org types.

Open Graph describes a link. JSON-LD describes the thing on the page. A search engine can read a course, an event, or a recipe and show it differently in results.

html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Course",
  "name": "Kodingu HTML",
  "description": "Learn the structure of a web page.",
  "provider": { "@type": "Organization", "name": "Kodingu" }
}
</script>

The script element carries data, not code. Browsers ignore it and search engines parse it. The @context names the vocabulary, and @type names the kind of thing being described.

Note

JSON has no comments and no trailing commas. A single stray comma makes the whole block unreadable, so paste it into a validator before shipping.

Your turn

Challenge

Add a JSON-LD block that describes a Course named "Kodingu HTML", with the description "Learn the structure of a web page." and a provider named "Kodingu".

  • Use a script element with type="application/ld+json".
  • The block parses as valid JSON.
  • Set @context to https://schema.org and @type to Course.
  • Set name to "Kodingu HTML" and description to "Learn the structure of a web page.".
  • Give the provider the name "Kodingu".
