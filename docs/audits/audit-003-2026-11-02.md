## Fixed during the audit

1. **Reading measure.** Lesson theory, notes, challenge prompts, and project links ran at 94–101ch; progress mission descriptions at 112–128ch. Body prose is capped at 62ch, mission descriptions at 56ch. Code blocks and the editor keep the full column width.
2. **Desktop lesson column.** The main column was capped at 760px inside an 816px track, leaving a 56px dead band at the right edge. The layout now uses `17rem minmax(0, 760px)` with `space-between`, so the column is flush with the shell and the outer gutters match.
3. **Tablet hero alignment.** At 768px the demo panel was capped at 640px while the copy above it was 672px, so the demo ended 32px short. Both now share the same 42rem measure.
4. **Copy button.** Raised from 26px to 32px on desktop. It was already 44px on touch widths.
5. **Practice eyebrow.** Added breathing room between the breadcrumb and the "Extra practice" section label.

## Harness improvements

`scripts/audit-ui.mjs` now:

- treats a radio or checkbox as covered when its wrapping label is at least 44x44;
- checks inner grid tracks for dead space, skipping stacked layouts that deliberately cap their measure;
- uses an 80ch wide-text threshold (the first pass used 95ch);
- walks 22 tab stops per page and reports any tab stop without a visible focus ring;
- reads the reduced-motion transition duration;
- captures viewport screenshots of the mobile demo and lesson editor, because full-page captures can paint iframes blank.
