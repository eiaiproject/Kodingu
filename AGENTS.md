## antislop

This project follows the antislop rules. The skill files are installed at `~/.agents/skills/antislop/`.

For UI, copy, people, mobile layout, or code comments work, read the core and then the skill for the task:

- Core: `~/.agents/skills/antislop/SKILL.md`
- UI / visual: `~/.agents/skills/antislop-ui/SKILL.md`
- Copy and text: `~/.agents/skills/antislop-copywriting/SKILL.md`
- People: `~/.agents/skills/antislop-human/SKILL.md`
- Mobile / responsive: `~/.agents/skills/antislop-layoutmobile/SKILL.md`
- Code comments: `~/.agents/skills/antislop-code/SKILL.md`

Resolve the usage mode in this order: explicit session choice, global preference, then ask. Announce the mode and its source once before UI work.
