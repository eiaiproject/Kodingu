## Fixes

### 1. Preview iframes no longer enter the keyboard tab order

Rule: R-32.
Files: `index.html`, `assets/js/lesson.js`, `assets/js/project.js`, `assets/js/challenge.js`.

The four preview iframes now carry `tabindex="-1"`:

- `#demo-frame` on the home page.
- `#editor-frame` in the lesson player.
- `#project-frame` in the project workspace.
- `#challenge-frame` in the challenge workspace.

A trial `iframe:focus` outline was removed after Chromium reported the iframe as `document.activeElement` while `:focus` and `:focus-within` did not match. No dead CSS was kept.

Verified focus behavior:

| Page | Frame tabindex | Next Tab stop |
|---|---|---|
| Home | -1 | First course row |
| HTML lesson | -1 | Show hint |
| CSS lesson | -1 | Show hint |
| JavaScript lesson | -1 | Show hint |
| Project | -1 | First checklist input |
| Challenge | -1 | Show hint |

### 2. Mobile navigation has a visible Menu label

Rule: R-03.
Files: `assets/js/app.js`, `assets/css/app.css`.

The screen-reader-only label is now a visible `.nav-toggle-label` text node beside the Reicon Menu glyph. The button keeps its accessible name from the visible text.

Verified:

- 320px: 79x44 button, label visible, page overflow 0.
- 390px: 79x44 button, label visible, page overflow 0.
- 768px: 79x44 button, label visible, page overflow 0.
- 1280px: toggle hidden; full navigation row remains.
- Menu opens with `aria-expanded="true"`, first link receives focus, and Escape closes it and returns focus to the toggle.
- Label contrast: 8.17:1 in the light theme.

### 3. Catalog course titles meet the 44px target at every width

Rule: R-03.
File: `assets/css/app.css`.

The catalog title now carries the padding and compensating margin at the base rule, not only below 720px. The visual position of the title is unchanged; the click target grows.

Verified `.catalog-title` heights:

- 320px and 390px: 44px.
- 768px, 860px, 861px, and 1280px: 49px.
- Before the fix: 35px at 768px.
- Page overflow at every tested width: 0.
